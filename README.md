# Project Overview

This project uses two databases: MongoDB and Redis. Redis is utilized as an in-memory database, where user data is stored for faster access compared to MongoDB.

## Registration System

A custom session algorithm was developed for the registration process, which actively works with cookies to provide a professional and adaptive registration system. This approach ensures a more reliable and efficient registration process.

## Client-Side

For the client-side, Next.js was used. I chose it not only for its speed but also for its unique built-in algorithms. What I particularly like about Next.js is how it handles both client and server components, as well as its routing system and metadata (SEO) management. These features allow for flexible meta-data configuration and provide extensive capabilities for SEO optimization.

## Server-Side

For server-side management, Redux Toolkit was implemented. This is one of the best solutions for projects with numerous server requests, as it ensures excellent performance and simplifies state management.

## Styling

Styled-components were used for styling the components. I selected it due to its flexibility and scalability, which makes it easy to adapt the project to future changes and developments.

## Technologies Used

- **MongoDB**: Database for storing persistent data.
- **Redis**: In-memory database for faster user data retrieval.
- **Next.js**: Framework for building the client-side application.
- **Redux Toolkit**: State management solution for handling server requests.
- **Styled-components**: Library for styling components in a scalable way.
